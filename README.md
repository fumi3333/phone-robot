# Phone-as-a-Brain: Toyota 86 Emotional Autonomous Vehicle

市販のトイラジコン（ジョーゼン 1/16スケール トヨタ86 4WD）に、スマートフォン（Galaxy Note 10+）を搭載し、スマートフォンの演算能力（Snapdragon 855、**RAM 12GB**、ToF深度カメラ、超広角カメラ）を「大脳」として活用した超低コスト自律走行ロボットプラットフォームです。

UCLA RoMeLa（*PhoneBot*）および UC Berkeley BAIR（*OpenBot*）の「Phone-as-a-Brain」アーキテクチャの設計思想を取り入れています。

---

## 1. 特徴 (Features)
- **はんだ付け完全不要（ネジ締めのみ）**:
  ドライバー1本で配線できる「L298N ネジ式端子台」を採用。
- **電源分離による安定駆動 (No-Reset Architecture)**:
  ESP32マイコンはスマホ（Galaxy Note 10+）のType-C端子から直接給電。モーターは車載の単3×6本（9.0V）から独立給電するため、モーター始動時の電圧低下によるマイコンリセットを物理的に防止。
- **ESP32 LEDC ハードウェアPWM (v2.1)**:
  SPIフラッシュ干渉のない安全ピン（GPIO 16, 17, 18, 19）と、ステアリング過熱保護タイマー、室内走行用速度リミッター（PWM 160）を搭載。
- **Google MediaPipeによるリアルタイム感情・表情認識**:
  エッジブラウザ上で顔検出・表情（笑顔・集中）を完全ローカル推論。人が笑顔を見せると嬉しそうに駆け寄るエモーショナル追従走行を実装。
- **テスラ/FSD風サイバーHUD ＆ ワンタップSNS動画録画 (REC)**:
  速度計、操舵角、ターゲットロックオン枠、パースペクティブ道路グリッドを30fpsでリアルタイム描画。ワンタップでスマホ内に合成動画（.webm）を録画保存可能。

## 2. 実機仕様書 (Specifications)

### 車体：ジョーゼン ダートマックス 1/16 トヨタ86 4WD (JRVC015-RD)
- 全長 260mm × 幅 110mm × 高さ 80mm
- シャフトドライブ式 4輪駆動（4WD）＋ 独立フロントステアリング
- 単3形乾電池 × 6本（公称 9.0V / 充電池で 7.2V）
- 付属：ラバータイヤ ＋ ドリフトタイヤ
- 通信：40MHz帯（純正プロポ）

### 頭脳：Galaxy Note 10+ (RAM 12GB / Snapdragon 855)
- 高さ 162.3mm × 幅 77.2mm / 重量 約196g（1/16ルーフにジャストフィット）
- RAM 12GB（エッジAIモデルを常駐させても余裕のメモリ）
- カメラ：F1.5/F2.4可変絞りメイン広角 ＋ 123度超広角 ＋ ToF 3D深度センサー
- USB Type-C（OTGホスト通信 ＋ マイコンへの5V給電）

## 4. 完全配線図 (Wiring Diagram)

```text
【Galaxy Note 10+】
       │ [USB-C ケーブル (通信 + 5V給電)]
       ▼
【ESP32 Type-C】 (ピン実装済み)
   GPIO 16 ──────────> L298N [IN1] (走行 前進)
   GPIO 17 ──────────> L298N [IN2] (走行 後退)
   GPIO 18 ──────────> L298N [IN3] (操舵 左折)
   GPIO 19 ──────────> L298N [IN4] (操舵 右折)
   GND     ──────────> L298N [GND] (共通グラウンド) ※超重要！

【車載 単3×6本 電池ボックス (9V)】
   プラス側赤線 ─────> L298N [+12V端子] (ネジ留め)
   マイナス側黒線 ───> L298N [GND端子]   (ネジ留め)

【ラジコンのモーター】
   走行4WDモーター線(2本) ──> L298N [OUT1, OUT2] (ネジ留め)
   操舵ステアリング線(2本) ─> L298N [OUT3, OUT4] (ネジ留め)
```

## 5. 段階的テスト手順 (Step-by-Step)

1. **第0段階（改造前）**:
   新品の電池を入れ、純正の状態で正常に前後・左右に走ることを確認。
2. **第1段階（机上テスト）**:
   車輪を宙に浮かせ、PCのシリアルモニタから `f`（前進）、`b`（後退）、`l`（左）、`r`（右）、`s`（停止）を送信して動作確認。
3. **第2段階（実走テスト）**:
   スマホを屋根に前下がり10〜15度で固定し、ブラウザで [https://fumi3333.github.io/phone-robot/](https://fumi3333.github.io/phone-robot/) を開いてUSB接続。「▶ AUTO」で人物追従走行を開始。
