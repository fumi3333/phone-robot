# phone-robot

スマートフォンを頭脳とする自律走行ロボットの開発記録および実装一式。

市販のトイラジコン（ジョーゼン ダートマックス 1/16 トヨタ86 ドリフトドライブ、型番 JRVC015-RD）をベース車体とし、車載スマートフォン（Galaxy Note 10+）のカメラ・深度センサー・演算能力を用いて、室内の地図を作成しながら自律走行することを目的とする。

本リポジトリは MIT ライセンスで公開する。

- アプリ配布: [GitHub Releases](https://github.com/fumi3333/phone-robot/releases)（APK）
- Web 版 HUD: https://fumi3333.github.io/phone-robot/

## システム構成

| 部位 | 実体 | 役割 |
| --- | --- | --- |
| 頭脳 | Galaxy Note 10+（Snapdragon 855 / RAM 12GB / ToF 深度カメラ） | 知覚・自己位置推定・地図作成・経路計画・走行判断 |
| 中継 | ESP32 開発ボード（Lzxuan、Type-C、CH340C） | スマホからの走行命令をモータードライバへ中継 |
| 駆動 | モータードライバ（後述） | 駆動モーターとステアリングモーターへ電池の電力を供給 |
| 車体 | ジョーゼン 1/16 トヨタ86（JRVC015-RD） | 駆動モーター（後輪）・ステアリングモーター（前輪）・単3×6本の電池ボックス |

通信は USB 有線シリアル（115200bps）のみを用いる。使用する ESP32 ボードには日本の技適マークがないため、Wi-Fi / Bluetooth は有効化しない。

走行命令の形式は `c,<drive>,<steer>` および単文字コマンド（f / b / l / r / s）。通信が 400ms 途絶えた場合はファームウェア側で自動停止する。

## ソフトウェアの実装状況

### Flutter アプリ（`flutter/`）

- 地図化の中核（占有格子地図・フロンティア探索・A* 経路計画）を Dart で実装し、シミュレーションと実機で同一のコードを用いる。
- 地図仕様: セル 5cm、対象室 6m × 5m、深度は ToF から取得する 21 本のレイに正規化する。
- シミュレーションでの測定結果: 探索のカバレッジ 96.9〜97.6%、既知セルの正解率 約 95.6%。
- 巡回機能一式を実装済み: 帰還、経路の記録と再生、立入禁止区域の指定、前回巡回との変化検出、巡回レポートの自動生成。いずれもシミュレーションで検証済み。
- 実機向けの安全対策を実装済み: 自己位置の喪失・深度データの停滞・USB 切断・画面消灯の各事象で、誤った地図を書かずに停止する。
- ARCore 連携（自己位置・Raw Depth の取得）と USB シリアル連携は Android ネイティブ層（Kotlin）に実装。
- v0.2.0 を GitHub Releases で公開済み。APK は GitHub Actions で自動ビルドされる。

### Web 版 HUD（`web/`、`index.html`）

- ブラウザの Web Serial で ESP32 と接続し、手動操縦と、走行動画（MP4）と時刻付き走行命令ログ（CSV）の同時記録ができる。

### ファームウェア（`firmware/`）

- ESP32 用。GPIO16〜19 に走行・操舵の 4 信号を割り当て、LEDC による PWM 制御を行う。
- 実機での検証完了: PC からの認識（COM7）、書き込み、起動バナーの受信、走行命令への応答を確認した。

### 学習パイプライン（`notebooks/`）

- 公開走行データを用いた End-to-End 学習と TFLite 変換のノートブック、および単眼深度推定モデルの TFLite 変換ノートブックを収録する。

## ハードウェアの状況（2026-10-31 時点）

完了している作業は次の通り。

- 車体の分解と内部確認。
- 純正受信機基板の全配線の同定（駆動モーター、ステアリングモーター、電源スイッチ、ライト、アンテナ）。
- 駆動モーターの配線 2 本を基板から取り外し済み。

未完了の作業と、その理由は次の通り。

- 駆動モーターの動作確認（電池の直結テスト）は未確定である。単3 1 本での試行では電圧不足のため判定できず、電池ボックス 6 本での再テストを残している。
- モータードライバは、当初購入した MX1508（ハンダ付け前提）から、ネジ端子で配線できる L298N モジュールへ方針を変更した。ハンダ付け作業を前提としないための変更である。
- スマートフォンの車載マウントは設計済みで、未製作である。
