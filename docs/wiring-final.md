# 86 配線マップ（確定版）

この文書が、86 の配線についての唯一の正本である。配線で迷ったら、他の要約や図ではなくこの文書を見る。

## 部品

- マイコンボード: Lzxuan ESP32-DevKitC（CH340C、USB Type-C）
- モータードライバ: KKHMF MX1508 デュアル H ブリッジモジュール（端子は +、−、IN1〜IN4、MOTOR-A、MOTOR-B）
- 車体: Jozen Dirt Max 1/16 Toyota 86（型番 JRVC015-RD）
- 車体の電池: 単3 × 6 本

## ESP32 と MX1508 の信号線

書き込み済みで動作確認済みのファームウェア（LEDC PWM）に合わせた配線である。

- GPIO16（D16） → IN1
- GPIO17（D17） → IN2
- GPIO18（D18） → IN3
- GPIO19（D19） → IN4
- ESP32 の GND → MX1508 の −（共通グランド。必須）

## モーターの接続

- MOTOR-A = 後ろの駆動モーター（赤と黒のペア。純正基板から外し済み）
- MOTOR-B = 前のステアリングモーター（オレンジ色の 104 コンデンサが付いた端子の、赤と黒のペア）
- 前のモーターには、工場出荷時から 104（0.1 µF セラミックコンデンサ）が付いている

## 電源

- 車体の電池プラス → 純正スライドスイッチ → スイッチ中央の赤い線 → MX1508 の +
- 電池マイナスの線 → MX1508 の −
  - 電池マイナスの線は、電池ボックスのバネ側の端子から辿って特定する
- ESP32 の電源: ベンチテストでは PC の USB。最終形はスマホの USB（データと電源を 1 本のケーブルで兼ねる）
- モーター用電源と ESP32 用電源は分ける（2026-11-05、槌屋先生の指導）

## コンデンサ

- 各モーターの 2 つの端子の間に、0.1 µF のセラミックコンデンサを 1 つずつ付ける（2026-11-05、槌屋先生の指導。同日の相談の文字起こしで確認済み）
- 1000 µF の電解コンデンサは付けない。その数字は外部 AI の要約に出てきたもので、ホワイトボードの写真にも相談の文字起こしにも無い

## 作業の決まり

- はんだ付けの間は、電池を抜き、スイッチを OFF にする
- 初めて電源を入れる前に、はんだブリッジと短絡が無いか確認する
- 初回の動作確認は、短いパルスだけで行う

## 未確認の事項

- 前のモーターハウジングの、上側の余った黒い線と下側の赤い線の役割（電池の直結テストで確定する）
- ステアリングが比例制御かオンオフか（電池の直結テストで確定する）
- 浮いている黒い線のうち、どれが電池マイナスか（電池ボックスのバネ側の端子から辿って確定する）
