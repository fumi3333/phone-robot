## 配線図 v2（この日の夜に確定形）

- 確定（合意）: 接続は全10本。
  1. 電池＋ → スイッチ → MX1508 の＋端子
  2. 電池− → MX1508 の−端子
  3. ESP32 D16 → IN1
  4. ESP32 D17 → IN2
  5. ESP32 D18 → IN3
  6. ESP32 D19 → IN4
  7. ESP32 GND → MX1508 の−端子（共通グランド必須。無いと信号が届かない）
  8. MOTOR-A → 後ろの駆動モーター（赤・黒、外し済み）
  9. MOTOR-B → 前のステアリングモーター（赤・黒、基板から根元で切る工程が残る）
  10. 各モーターの2線間に 0.1µF セラミックコンデンサ
- 確定（合意）: ESP32 が使うピンは D16・D17・D18・D19・GND の5本だけ。基板のシルク印刷の文字で探す。他のピンは触らない。
- 確定（合意）: ESP32 の電源の最終形はスマホ USB（データと電源が1本）。先生の留保は安定性のみ。確認順は、先に PC の USB で机上テスト、次にスマホ USB に替えて同じ動作かを見る。
- 成果物: docs/wiring-diagram-esp32-mx1508.html（配線図 v2）。

## その他

- 確定（実査）: MX1508 の仕様を製品ページとデータシートで確認。電源 2〜10V、信号入力 1.8〜7.0V（ESP32 の 3.3V で駆動可）、1.5A/ch・ピーク 2.5A、真理値表（1/PWM＋0 で正転、入替で逆転、0/0 で待機、1/1 でブレーキ）。ロジック電源はモーター電源と単一。
