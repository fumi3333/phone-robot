## ハードの状態（2026-11-15 時点）

- 分解完了（2026-10-30）。配線の同定は図 v9 が確定形。
  前のモーター = ステアリング用（シャフトに繋がっていない）。基板の一番左の赤が前モーター行き。
  駆動ペア = 基板の右から3番目の赤 ＋ 右から2番目の黒 → 後ろのモーター。
  電源スイッチは車体裏面のスライドノブ。内側の茶色い板に赤・赤・黒の3本（電池＋ → スイッチ → 基板）。
  電池ボックスは車体の一部。裏面の白いダイヤルはステアリングのトリム。
  ライトは細い赤・緑・黒で基板左上 → 殻側の白い3端子ブロック。
  アンテナは基板右上から車体右側を下る黒い線。
- 駆動ペアは本人がはんだを外し済み（2026-10-30、初めてのはんだ作業。基板側の焦げは見た目だけ、基板は退役）。

## 決まったこと

- ドライバは MX1508。配線は docs/wiring-diagram-esp32-mx1508.html の10接続が確定形。共通グランド（ESP32 GND → MX1508 の−）が必須。
- ファームのピン割り当て: GPIO16→IN1、17→IN2、18→IN3、19→IN4（LEDC PWM）。
- 電源分離: モーター用（車体電池）と ESP32 用を混ぜない。ESP32 の電源の最終形はスマホ USB。確認順は PC の USB で机上テスト → スマホ USB で同動作を確認。
- はんだ付けルートで行く（2026-11-05 本人決定）。はんだ付けは6か所（電源2＋モーター4）。
- 純正の緑基板は外す（2026-11-15）。アンテナも一緒に外す。残し物は3つ: (1) スイッチの先を MX1508 の＋へ繋ぎ直す（スイッチ自体は残す）、(2) 前モーターの線はモーター側に長めに残して MOTOR-B へ、(3) ライトの線は外してよい（殻側の端子に残せば戻せる）。
- 組み立ての順番: (1) 後ろモーター単体の直結テスト → (2) 接続1〜8（駆動モーターだけ、短いパルス） → (3) 接続9〜10（ステアリング）。通電前にテスターで導通と短絡を確認。パルスは短く、確認したらすぐ切る。
- お手本（模倣学習の教師データ大量収集）は主軸にしない。公開モデルを使って 86 に合わせる。技術スタックは docs/tech-stack-public-models.md。
- VLA は第3段の将来枠。今は作らない。入れるときは2階建て（VLA は粗い行き先だけをゆっくり判断、止まる・避けるの細かい制御はルール側）。学習は Colab、スマホは推論だけ。
- ログの形式: MP4 動画 ＋ ミリ秒の時刻つきコマンド CSV。
