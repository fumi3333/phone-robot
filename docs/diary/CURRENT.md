## プロジェクト

- Phone-as-a-Brain の自律走行ロボット。ベースはジョーゼン 1/16 トヨタ86 ドリフトドライブ（JRVC015-RD、JAN 4950344159243）。約260×110×80mm、4WD、制御は 40MHz 電波（純正）。
- 頭脳はスマホ（Galaxy Note 10+、Snapdragon 855、RAM 12GB、ToF 深度カメラ）。ESP32 が伝令。MX1508 がモーター駆動。動力は車体の単3×6（アルカリ 9.0V / ニッケル水素 7.2V）。
- 目的は「AIモデル（VLA）を載せること」ではなく、「車体が動けるワンフロアのマップ（占有格子地図）をスマホのカメラ＋ARCoreだけで自律走行して作ること」。（2026-11-15 本人再確定）
- Musalink（教科書BOX）とは別プロジェクト・別リポジトリ。（確定・本人）

## ハードの状態（2026-11-15 時点）

- 分解完了（2026-10-30）。配線の同定は図 v9 が確定形。
  前のモーター = ステアリング用（シャフトに繋がっていない）。基板の一番左の赤が前モーター行き。
  駆動ペア = 基板の右から3番目の赤 ＋ 右から2番目の黒 → 後ろのモーター。
  電源スイッチは車体裏面のスライドノブ。内側の茶色い板に赤・赤・黒の3本（電池＋ → スイッチ → 基板）。
  電池ボックスは車体の一部。裏面の白いダイヤルはステアリングのトリム。
  ライトは細い赤・緑・黒で基板左上 → 殻側の白い3端子ブロック。
  アンテナは基板右上から車体右側を下る黒い線。
- 駆動ペアは本人がはんだを外し済み（2026-10-30、初めてのはんだ作業。基板側の焦げは見た目だけ、基板は退役）。
- ESP32 の検証完了（2026-10-30）。COM7（CH340）、起動OK、ファームのバナー TOYOTA86_ESP32_LEDC_ONLINE、コマンド f / s / c,150,-100 を処理。電波を出すコードはゼロ（手持ちの ESP32 は技適マーク無しのため有線 USB のみ）。115200bps、ウォッチドッグ 400ms、プロトコルは c,drive,steer と単文字コマンド。PWM は LEDC で GPIO16-19。
- 部品の手持ち: ESP32（Lzxuan、ESP32-D0WDQ5-V3、USB Type-C、51×28mm）、MX1508 モジュール（KKHMF 3個入り）。購入済み合計 1,998円（2026-10-30）。
- はんだごての台が到着し、組み立てセッションを開始（2026-11-15）。買ったこて本体と台の型番は未報告。
- ファームの PWM 不具合を修正し、as-built 版を書き込み済み（2026-11-15）。コア 3.3.12 では ledcWrite がピン番号を取るのにチャンネル番号を渡していた問題を `pwmWrite` ヘルパーで解消。テスター（サンワ 360-YTR）で GPIO18 の出力電圧 1.94V を確認し、単3電池を入れて後ろ駆動モーター（MOTOR-B）の 20秒/30秒連続回転を確認済み。
- さらに `esp32_toyota86_asbuilt.ino` で `MAX_DRIVE_PWM = 255` へ上限解放し、`setSteer` もサーマルスロットルなしの 100% デューティ出力（255）へ更新済み（コンパイル確認済み、フラッシュ 21% / RAM 6%）。
- ステアリング（MOTOR-A）はバンバン（左フル／中央バネ／右フル）＋スリップクラッチ構造。静止時の据え切りではスリップクラッチが逃げて切れ角が浅いが、駆動輪を回しながらの走行中（および純正リモコン使用時）はバネに勝って左右へ切れることを本人と実機で確認。
- 急加減速時の電流ショックや振動で USB ポートが COM8 → COM7 へ再認識される現象を確認。PC テスト用 `steer_test.ps1` に CH340 自動検出と反転間 800ms 停止を実装済み。
- 配線の正本は docs/wiring-final.md（MOTOR-A＝前ステアリング、MOTOR-B＝後ろ駆動）。
- テスターは手持ちのサンワ YX-360TRF / 360-YTR（アナログ）。

## 決まったこと

- ドライバは MX1508。配線は docs/wiring-diagram-esp32-mx1508.html の10接続が確定形。共通グランド（ESP32 GND → MX1508 の−）が必須。
- ファームのピン割り当て: GPIO16→IN1、17→IN2、18→IN3、19→IN4（LEDC PWM）。
- 電源分離: モーター用（車体電池）と ESP32 用を混ぜない。ESP32 の電源の最終形はスマホ USB。確認順は PC の USB で机上テスト → スマホ USB で同動作を確認。
- はんだ付けルートで行く（2026-11-05 本人決定）。はんだ付けは6か所（電源2＋モーター4）。
- 純正の緑基板は外す（2026-11-15）。アンテナも一緒に外す。残し物は3つ: (1) スイッチの先を MX1508 の＋へ繋ぎ直す（スイッチ自体は残す）、(2) 前モーターの線はモーター側に長めに残して MOTOR-B へ、(3) ライトの線は外してよい（殻側の端子に残せば戻せる）。
- 組み立ての順番: (1) 後ろモーター単体の直結テスト → (2) 接続1〜8（駆動モーターだけ、短いパルス） → (3) 接続9〜10（ステアリング）。通電前にテスターで導通と短絡を確認。パルスは短く、確認したらすぐ切る。
- お手本（模倣学習の教師データ大量収集）は主軸にしない。公開モデルを使って 86 に合わせる。技術スタックは docs/tech-stack-public-models.md。
- VLA は第3段の将来枠。今は作らない。入れるときは2階建て（VLA は粗い行き先だけをゆっくり判断、止まる・避けるの細かい制御はルール側）。学習は Colab、スマホは推論だけ。
- ログの形式: MP4 動画 ＋ ミリ秒の時刻つきコマンド CSV。
