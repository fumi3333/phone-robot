## プロジェクト

- Phone-as-a-Brain の自律走行ロボット。ベースはジョーゼン 1/16 トヨタ86（JRVC015-RD）。
- スマホ（Galaxy Note 10+）が脳。ESP32 が伝令。L298N がモーター駆動。単3×6（充電池可）が動力。

## 決まったこと

- 純正コントローラーでの動作確認は省略する。9V電池は買わない。（確定・本人）
  どうせマイコン化でコントローラーは不要になるため。
- 車体側の単3×6は必要。本人の東芝の充電池＋充電器で賄う。（確定・本人）
- 配線の前に、モーターへ電源直結で回るかだけ確認する。（確定・合意）
- ドライバは L298N で統一する方向。ネジ端子ではんだ不要。（暫定・ハンドオフ確定部品）
- マイコンは ESP32 で統一する方向。ただし現行ファームのピン番号は
  Arduino Nano 前提（5/6/9/10）で、ESP32 用の書き換えが必要。（確定・実査で判明）
- 電源はモーター側とロジック側を分けるのが安全。AMS1117 一本は熱と電圧降下が不安。（暫定・提案）

## ソフトの方針

- スマホ側は Flutter のネイティブアプリ化を狙う。（確定・本人提案）
  理由: ARCore の Depth API で壁までの距離が「推測」でなく「計測」になる。
  モーショントラッキングで自己位置も追え、マップ作成に近づく。
  Bluetooth 直接接続も開ける。ハード側のファームはそのまま使える。
- ソフトの難易度は気にしない。AIを使う前提で、難しくてもよい。（確定・本人）
