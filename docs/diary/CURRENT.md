## 決まったこと

- 純正コントローラーでの動作確認は省略する。9V電池は買わない。（確定・本人）
  どうせマイコン化でコントローラーは不要になるため。
- 車体側の単3×6は必要。本人の東芝の充電池＋充電器で賄う。（確定・本人）
- 配線の前に、モーターへ電源直結で回るかだけ確認する。（確定・合意）
- ドライバは MX1508 ミニモジュール（MOSFET駆動・2ch）で確定。大型L298Nのような約2Vの電圧降下（約28%の電力ロス）がなく、充電池7.2Vのパワーがそのままモーターに届く。親指サイズで車体内に余裕で収まり、走行時の耐振動性が高いハンダ直結で配線。（確定・2026-10-30）
- 購入部品が到着（ESP32-DevKitC Type-C Lzxuan版 ＋ MX1508 3個入）。ESP32缶の刻印に技適マークがないため、法律順守で Wi-Fi / Bluetooth は絶対に有効化せず、USB-C 有線シリアル通信のみで運用する。（確定・2026-10-30）
- PC側で USB-SERIAL CH340 (COM7) として正常認識。チップブート（ESP-IDF v3.0.3, Flash 4MB）を確認し初期不良なし。（確定・実査・2026-10-30）
- マイコンは ESP32 で統一。ファームウェア（esp32_toyota86.ino）は GPIO 16/17/18/19 への再配置および LEDC PWM へ書き換え・コンパイル成功済み。（確定・反映済み）
- 電源はモーター側（単3×6本・東芝充電池）とロジック側（スマホのUSB-Cから5V直給電）に完全分離。電圧降下リセットと降圧発熱を物理的に防止。（確定・反映済み）

## ソフトの方針

- スマホ側は Flutter のネイティブアプリ化を狙う。（確定・本人提案）
  理由: ARCore の Depth API で壁までの距離が「推測」でなく「計測」になる。
  モーショントラッキングで自己位置も追え、マップ作成に近づく。
  Bluetooth 直接接続も開ける。ハード側のファームはそのまま使える。
- ソフトの難易度は気にしない。AIを使う前提で、難しくてもよい。（確定・本人）
