# トヨタ86 × Galaxy Note 10+ 自律運転ハードウェア仕様・配線マニュアル

本書は、株式会社ジョーゼンのトイラジコン「1/16 トヨタ86 4WD（JRVC015-RD）」に「Galaxy Note 10+」を搭載し、はんだ付けなし・完全ネジ留めで自動運転化するための公式ハードウェア仕様書および作業手順書です。

---

## 1. 使用機材の仕様書 (Specifications)

### ① 車体：ジョーゼン ダートマックス 1/16 トヨタ86 4WD (JRVC015-RD)
- **スケール・寸法**: 1/16スケール（全長 260mm × 全幅 110mm × 全高 80mm）
- **駆動方式**: **シャフトドライブ式 4輪駆動（4WD）**（前後輪すべてが回るため高トルク）
- **ステアリング**: 電磁石/DCモーターによる左右振り切り方式（センター復帰スプリング付き）
- **車載電源**: **単3形乾電池 × 6本（公称 9.0V / 充電池で 7.2V）**
  - 車体裏側のバッテリールームに格納。モーター駆動用のメイン電源として使用。
- **付属タイヤ**: ラバーグリップタイヤ ＋ ドリフト専用樹脂タイヤの2系統
- **純正通信規格**: 40MHz帯 アナログ電波（コントローラー側に9V角形電池使用）

### ② 頭脳：Galaxy Note 10+ (SC-01M / SCV45 / 楽天版 SM-N975C)
- **寸法・重量**: 高さ 162.3mm × 幅 77.2mm × 厚さ 7.9mm / 重量 約196g
  - 1/16スケールのルーフ（幅110mm）の中央に安定して搭載可能。
- **SoC・演算性能**: Qualcomm Snapdragon 855（Octa-core 最大 2.84GHz）
  - GPU: Adreno 640（WebGL / Canvas HUDを60fps描画）
  - NPU/DSP: Hexagon 690（Google MediaPipe顔・感情認識を完全ローカルでリアルタイム処理）
- **メモリ (RAM)**: **12GB LPDDR4X**（超大容量。バックグラウンド処理や画像認識でも枯渇ゼロ）
- **カメラ性能**:
  - メイン広角: 1200万画素 (F1.5/F2.4 可変絞り・OIS)
  - 超広角: 1600万画素 (画角123度・足元から前方までワイドに捕捉)
  - **ToF (Time-of-Flight) 3D深度カメラ**: 赤外線による距離・空間寸法計測に対応
- **外部端子・給電**: USB Type-C (USB 3.1 Gen1 / OTGホスト機能)
  - **スマホのType-C端子から車載ESP32マイコンへ直接5V給電可能**（降圧回路不要）。

## 3. 電源分離と完全配線図 (Wiring Diagram)

モーター始動時の電圧低下でマイコンがリセットする事故を防ぐため、**「ロジック電源（スマホ給電）」と「モーター電源（単3電池）」を完全に分離し、GNDのみを共通化**します。

```text
【Galaxy Note 10+】
       │ [USB-C ケーブル (通信 + 5V給電)]
       ▼
【ESP32 Type-C】 (はんだ不要・ピン実装済み)
   GPIO 16 ──────────> L298N [IN1] (走行 前進)
   GPIO 17 ──────────> L298N [IN2] (走行 後退)
   GPIO 18 ──────────> L298N [IN3] (操舵 左折)
   GPIO 19 ──────────> L298N [IN4] (操舵 右折)
   GND     ──────────> L298N [GND] (共通グラウンド) ※超重要！

【車載 単3×6本 電池ボックス (9V)】
   プラス側赤線 ─────> L298N [+12V端子] (ネジ留め)
   マイナス側黒線 ───> L298N [GND端子]   (ネジ留め)

【ラジコンのモーター (車体内から取り出し)】
   走行4WDモーター線(2本) ──> L298N [OUT1, OUT2] (ネジ留め)
   操舵ステアリング線(2本) ─> L298N [OUT3, OUT4] (ネジ留め)
```

> [!IMPORTANT]
> **ネジ留め作業のコツ**:
> 1. ラジコン本体から出ている電線の被覆をハサミや爪で5mmほど剥きます。
> 2. L298Nの青い端子台のネジを反時計回りに緩めます。
> 3. 剥いた銅線を穴の奥まで差し込み、プラスドライバーで時計回りにネジをしっかり締めます。これではんだ付けゼロで接続完了です。

## 4. 失敗しないための「段階的チェック手順」

一気に組み立てず、以下の3段階で動作を切り分けて進めます。

### 【第0段階：改造前の動作確認（関門）】
- 車体とコントローラーに**新品の電池（単3×6本、9V角形×1本）**を入れ、純正の状態で走るか確認する。
- 10年前の古い電池は電圧が抜けているため絶対に新品を使用すること。
- ここで動かない場合は、車体裏のスイッチ接触不良や電池の向きを確認する。

### 【第1段階：机上での空転テスト】
- 車体をティッシュ箱等の上に載せて、タイヤを完全に宙に浮かせた状態にする。
- PCとESP32をUSBで繋ぎ、Arduino IDEの「シリアルモニタ（115200bps）」を開く。
- キーボードで以下の文字を打ち、車輪が回るかテストする：
  - `f` + Enter → 4輪が前進回転
  - `b` + Enter → 4輪が後退回転
  - `l` + Enter → 前輪が左に切れる
  - `r` + Enter → 前輪が右に切れる
  - `s` + Enter → 全停止
- ※トイラジコンのステアリングは長時間の通電で熱を持つため、確認したらすぐ `s`（停止）を押すこと。

### 【第2段階：スマホ搭載と自律走行】
- Galaxy Note 10+ の背面にメラミンスポンジを挟んで前下がり10〜15度に傾け、養生テープでルーフに固定。
- スマホのChromeで [https://fumi3333.github.io/phone-robot/](https://fumi3333.github.io/phone-robot/) を開く。
- USB-CケーブルでスマホとESP32を直結し、「⚡ USB CONNECT」を押す。
- 最初は安全のため、ファームウェア側で最高速度を `PWM 160`（約60%出力）にリミット制限しています。
- 「▶ AUTO」を押して、前方に立った人の笑顔を検知して追従走行することを確認する。
